# What this is
A simple place for you to just put your little .dds files

Based on https://www.reddit.com/r/Battletechgame/comments/8emrs2/using_a_custom_mercenary_logo_how_to_guide/

# How you do it
In a nutshell, put in an _upside down_ .dds file inside "emblems". Then on load, I _think_ your new emblem/logo should be visible.

.dds files can be converted from .png files. I'm using GIMP, but there's a number of free image editing softwares out there that can probably do similar.
